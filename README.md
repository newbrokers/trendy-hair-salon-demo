# Trendy Hair Salon — concept demo

Concept website built for outreach to **Trendy Hair Salon**, a hair salon in
Agios Athanasios, Limassol, Cyprus (Krinou 8). Their Google Business listing
has a 4.9 rating from 16 reviews, is unclaimed, and has no website — this is
a first-draft concept to show them what a real site could look like.

- Built from the salon's real Google Business photos, rating, address, and phone.
- Services list is a generic placeholder — swap in the real menu before sending.
- `index.html` is fully self-contained (images embedded as base64) — deploy as-is to Vercel, no build step needed.
